# Enterprise SQL Database Architectures 🗄️

## 📌 Overview
This repository showcases the design and implementation of three distinct relational databases created to manage complex, multi-layered data systems. The focus of these projects is on **data integrity, schema mapping, and relational architecture**—essential concepts for standardizing and reconciling datasets in enterprise environments.

## 🏗️ Database Schemas Developed
1. **Campus_Event Database:**
   * Designed tables for user management, ticketing, waitlists, and secure transaction processing.
   * Built relational links between attendance tracking and financial payments to ensure data consistency.
2. **Grocery_Pickup Database:**
   * Modeled a supply-chain-style inventory and ordering system.
   * Created schemas for product inventory, substitution suggestions, delivery confirmations, and secure payment processing. 
3. **Apartment_Maintenance Database:**
   * Developed a ticketing and workflow architecture for tenant requests, severity tracking, and maintenance validation.

## 🎯 Data Quality & Analysis Focus
* **Data Standardization:** Enforced strict data types, primary/foreign key constraints, and unique identifiers to prevent data anomalies.
* **Workflow Mapping:** Structured the tables so that data flows logically from an initial user request all the way through to payment and resolution (similar to JIRA/ticketing workflows).
* **Tech Stack:** SQL, Relational Database Design, Data Architecture
